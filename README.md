# 🏅 Olympics Data Analysis — SQL Project

A SQL-based data analysis project exploring **120 years of Olympic Games history** using two datasets: athlete events and country/NOC region data.

---

## 📂 Files

| File | Description |
|------|-------------|
| `Olympics dataset.zip` | Raw dataset containing athlete events and NOC region tables |
| `SQLQuery_Olympics.sql` | All SQL queries solving 20 business problems |

---

## 🗃️ Dataset

**Tables Used:**
- **Athlete_Events** — athlete-level data including name, sport, event, medal, age, team, NOC, and year
- **NOC_region** — maps NOC codes to country/region names

---

## ❓ Problems Solved (20 Queries)

| # | Question |
|---|----------|
| 1 | How many Olympic Games have been held? |
| 2 | List all Olympic Games held so far |
| 3 | Total number of nations per Olympic Games |
| 4 | Year with highest and lowest country participation |
| 5 | Nations that participated in every Olympic Games |
| 6 | Sports played in all Summer Olympics |
| 7 | Sports played only once in Olympics history |
| 8 | Total sports played in each Olympic Games |
| 9 | Oldest athletes to win a Gold medal |
| 10 | Ratio of male to female athletes |
| 11 | Top 5 athletes with most Gold medals |
| 12 | Top 5 athletes with most medals overall |
| 13 | Top 5 most successful countries by medal count |
| 14 | Total Gold, Silver, Bronze medals by country |
| 15 | Medal breakdown by country per Olympic Games |
| 16 | Country with most Gold / Silver / Bronze per Games |
| 17 | Country with most medals of each type per Games |
| 18 | Countries that never won Gold but won Silver/Bronze |
| 19 | Sport where India won the most medals |
| 20 | India's Hockey medal breakdown by Olympic Games |
